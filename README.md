# BHDS_2010_Project4

Contributors: Abigail Beasley and Cole Harris

### Summary

This repo contains code to build an app for investigating trends in obesity prevalence and
diabetes mortality rates in the US, with a special focus on how these variables
differ across geographies. Potential causes for the rise in obesity and overweight
populations are also explored, including: income inequality, decreased access to food,
and poverty rates.

To see the dashboard, please visit: https://abigailbeasley.shinyapps.io/US_obesity_trends/

### File Summary

To see the code used to create the dashboard, visit app.R

For code pertaining to the exploratory analysis and data preprocessing please visit:

- obesity_exploratory_analysis.Rmd
- food scarcity_exploratory_analysis.Rmd
